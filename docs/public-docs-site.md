# Public Docs Site

This page describes the local preview for the public docs site.

## Purpose

The docs site should be the public-facing home for:

- install
- device identity
- onboarding
- credits
- releases

## Local Preview

The dashboard app serves a local docs preview at:

- `http://127.0.0.1:<port>/docs`

Use that preview to review the public copy before wiring the public domain.

## Review Rule

Any change to the docs site should keep the copy aligned with:

- `docs/install-page.md`
- `docs/device-identity-lifecycle.md`
- `docs/onboarding.md`
- `docs/credits-model.md`
- `docs/install-strategy.md`
