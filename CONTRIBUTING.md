# Contributing to MundusX

Thank you for contributing to MundusX.

## Principles

- Respect all contributors.
- Submit original work or work you have the right to contribute.
- Discuss major architectural changes before implementation.
- Keep changes focused and reviewable.
- Include documentation where appropriate.
- Ensure code builds and tests pass before submitting a pull request.

## Copyright

Unless otherwise agreed in writing, contributors retain copyright to their own contributions.

By submitting a contribution, you agree that your contribution may be distributed under the project's Apache License 2.0.

## Pull Requests

- Explain what changed and why.
- Link related issues or design notes when available.
- Keep generated build output out of commits.
- Prefer small, complete slices over broad unrelated changes.
